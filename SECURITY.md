# Security policy

Please report vulnerabilities privately through GitHub: this repository's **Security** tab, *Report a vulnerability*. Do not open a public issue for one.

What matters most here: anything that lets a web page, another user or another machine make this server spend a linked account, read a saved session, or
read an API key. The design and its known limits are in [docs/security.md](docs/security.md).

Only the latest release is supported.
